**Reading this correctly:** statement/line coverage is near 100% almost everywhere —
this suite is thorough. `main.jsx` at 0% is not a gap; it is the Vite entry point that
calls `ReactDOM.createRoot`, and no test imports it. The real finding is **branch**
coverage: every function in `recommend.js` and `validate.js` gets called, but not every
`?:`, `??`, `||`, or `if` inside them takes both paths. That is the list below.

## What this is and is not

- **Not a bug list.** Every item above is a defensive fallback or an edge input that
  the suite happens not to construct — not a wrong answer the suite is failing to
  catch. Two are flagged as genuinely unreached *statements* (brandMinAgeM's final
  `return null`, runWalk's unknown-vaccine branch) because those are the ones worth a
  deliberate "is this reachable at all" decision rather than just a missing test.
- **The recurring pattern** across both files is doses with a missing `date` field —
  `doses[0]?.date || null` / `?? null` fallbacks appear at 9 of the 39 sites above,
  almost always on dose 2 or a later dose. This lines up with §B2c of the plan
  ("the sweep never generates an invalid dose") and with the plan's item B property 5
  (`recommend()` never throws) — an undated middle dose is exactly the shape B2's
  "tight-spacing" profile and a widened grid should start generating.
- **No CI gate added.** Per the plan, `npm run test:coverage` is a manual command only;
  CI still runs `npm test`. A coverage threshold gate is explicitly deferred until
  after the rest of the plan (see plan §A, "Do NOT gate CI on a coverage threshold").

## Feeds forward into

- **Item B** (never-events sweep): properties 1, 5 and 6 should include patients with an
  undated middle dose — the single most common blind spot found here.
- **Item B2c** (tight-spacing profile): the grid's invalid-dose profile should include
  doses with a missing `date`, not only doses that are too close together.
- **Item C2** (hand-written clinical combos): none of the 39 branches above are
  clinical-combination gaps — this audit found no evidence there.
